# LEDControl-UnicornType

중국제 MGEX 카피 킷의 LED 컨트롤러를 제어하는 WeChat 미니앱을 대체하는 Android/iOS 앱 프로젝트.

## 상태
- 프로토콜 확보 단계 (Phase 0). 프레임워크는 프로토콜 분석 후 결정.
- 통신 방식: BLE (가정, 검증 필요)

## 로드맵
1. 프로토콜 확보 → `docs/protocol.md`
2. 프레임워크 결정 (Flutter 기본 후보)
3. 프로토콜 인코더 + MockDevice
4. UI / MVP (전원, 색상, 밝기, 효과, 프리셋)
5. Android/iOS 빌드

## 범위
본인 소유 기기와의 상호운용을 위한 프로토콜 분석에 한정한다.
